~~~mermaid
flowchart TD
    U["用户"]
    ENTRY["{用户入口}"]
    SVC["{服务编排}"]
    STORE[("持久化")]
    EXEC["{异步执行或下游系统}"]
    DATA[("{数据或文件来源}")]

    subgraph PATH_A["触发路径 A"]

    end

    SVC --> STORE

    EXEC --> DATA
    EXEC -->|状态和结果| SVC
    SVC --> STORE
    ENTRY -->|查询状态| SVC
~~~

流程说明必须明确：

- 哪些步骤由用户主动触发。

- 哪些数据是统一事实源。
- 哪些步骤异步完成，接口何时返回。
- AI、页面或第三方系统不得承担哪些职责。
